What you are looking at

A running prototype of the MuscleX member app, hitting the real Member BFF on localhost:4002 through a same-origin proxy. Nothing here is mocked: the occupancy number, the exercise list, set history and every workout you log are live API calls against the Iron Temple tenant.

Try the core loop

  • Tap the red + to start an empty workout.
  • Add Barbell Bench Press. The PREVIOUS column and the prefilled values come from GET /exercises/:id/history, an endpoint added today.
  • Tap a row's ✓. The set commits, the rest timer starts, and the next row prefills from the one you just finished.
  • Finish posts to POST /workouts/logs (also new) with an Idempotency-Key, and any PR comes straight back from the server.

Live gym occupancy on the Today tab is the Glofox half: the one thing Hevy and Strava structurally cannot do. It polls GET /gym/occupancy every 30s.

Floor traffic and the exercise catalogue are seeded dev data in the local Supabase. The endpoints, scoping and idempotency are real.
