# Purpose

This document defines every meaningful journey a user can experience throughout their lifetime with MuscleX.

The focus is not individual screens.

The focus is helping users achieve meaningful health outcomes.

Every feature should support one or more user journeys.

Every journey should reduce friction and increase long-term engagement.

---

# Journey Philosophy

Users do not wake up wanting to use MuscleX.

They wake up wanting to become healthier.

MuscleX exists to make that journey easier.
