# Purpose

This document identifies the real problems users hire MuscleX to solve.

Users do not download fitness applications because they enjoy logging data.

They use them to make progress toward meaningful personal outcomes.

Every feature within MuscleX must solve one or more Jobs To Be Done.

---

# JTBD Philosophy

People don't buy products.

People hire products to make progress.

When that progress stops,

they replace the product.

MuscleX must continuously help users move forward.

# Decision Framework

Before approving any feature, ask:

Which JTBD does it solve?

If the answer is:

None

↓

Reject.

Every feature must solve a real user problem.

---

# Success Statement

MuscleX succeeds when users stop thinking,

"I need to log another workout."

and instead think,

"MuscleX helps me become a healthier person."

That shift—from tracking activities to improving lives—is the foundation of the entire product.
