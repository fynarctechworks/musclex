# Purpose

This document is the single source of truth for every screen in the MuscleX platform.

Every screen must have:

• Unique Screen ID

• Module

• Parent Screen

• Navigation Entry

• Deep Link

• Feature Mapping

• API Mapping

• Analytics Mapping

• Acceptance Criteria

No screen may exist without being registered here.

---

# Screen ID Format

SCR-<MODULE>-<NUMBER>

Examples

SCR-HOME-001

SCR-WORKOUT-014

SCR-NUTRITION-008

SCR-GYM-022

SCR-AI-005

# Rules

- Every new screen must be added here before design begins.
- Screen IDs are permanent.
- Deleted screens are marked "Deprecated" but never reused.
- Every screen must map to at least one feature in the Feature Bible.
- Every screen must have a corresponding UX specification document.

---

# Success Criteria

- Every screen is discoverable.
- Every screen has a unique identifier.
- No duplicate functionality.
- No orphan screens.
- Every navigation path is traceable.
